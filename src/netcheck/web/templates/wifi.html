Getting into your router

Use your internet provider's app, or the settings address and admin password printed on the router's label.

{% endif %}

1. See who's connected

Open the list of connected devices ("Connected devices", "Attached devices" or "Clients") and match each one to something you own. Names are often unhelpful, like "ESP_3A1F".

If you can't account for something, change the Wi-Fi password. Every device has to reconnect, so anything that isn't yours drops off.

2. Check the encryption

Under "Security" or "Encryption", you want WPA2 or WPA3. WEP, plain WPA and Open are unsafe, so change them now.

3. Change default passwords

Change the Wi-Fi password and the router admin password if either is still the one on the label. Length matters more than symbols: four random words ("lamp-river-cobalt-tuesday") is stronger than "P@ssw0rd!".

4. Turn off what you don't use

  • WPS (push-button or PIN pairing): easy to attack on many routers.
  • Remote management ("Remote access", "Web access from WAN"): puts the settings page on the internet.
  • UPnP: lets devices open your firewall on their own. Leave it on only if a console or app needs it.
  • Port forwarding and DMZ: delete any rule you didn't set up.

5. Keep the router updated

Turn on automatic firmware updates if offered. Provider routers usually update themselves. If your own router hasn't had an update in years, replace it.

6. Use a guest network for gadgets

Put visitors and smart devices (cameras, plugs, TVs) on the guest Wi-Fi. If one is compromised, it can't reach your computers.

Signs something is wrong

  • Router settings or the admin password changed without you.
  • Websites redirect somewhere strange or show unexpected ads.
  • Your provider warns you about suspicious traffic.
  • Unknown devices come back after a password change.

If you think you've been hacked

  1. Factory-reset the router (hold the reset button for 10 to 30 seconds). Provider routers usually set themselves back up.
  2. Set new Wi-Fi and admin passwords straight away.
  3. Update the router's firmware, then go through steps 2 to 4.
  4. Update and scan your computers, then change important passwords, email first.
